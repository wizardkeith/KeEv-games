# Interchange conventions

All W0 geometry is original procedural graybox work. tools/assets.mjs is the actual authoring source, not a recovered Blender file. Regenerate with npm run assets. GLB is glTF 2.0, metre units, right handed, +Y up, +Z forward. Babylon uses a right handed scene to avoid destructive master mirroring. Root pivots are floor centre. Counter is 1.4 × 0.85 × 0.65 metres, separate from layout data. Runtime scales only the counter instance; its master is retained.

The independent test fixture is 0.35 × 1.4 × 0.3 metres. Skeleton GenericTwoBone has Root at floor and Upper at Y=0.7. GentleWave rotates the Upper bone around Z over 2 seconds with linear quaternion interpolation, no root motion and no attachment sockets. Normalized weights use up to two active influences, with four joint/weight channels. Zero-weight joint indices are zero. It is an abstract skinned block, neither a production character nor a pet. Validation and independent Babylon NullEngine import check skin and clip structure; actual rendered deformation and Unity orientation remain untested.

Materials use baseColorFactor, metallicFactor=0, roughnessFactor=0.85. No textures, normal maps, alpha blending, extensions, custom shaders or image masters exist for these procedural fixtures. Numeric base colours express material intent; Unity URP lighting/material appearance must be checked separately. Vertex normals are explicit. glTF validator reports zero errors and zero warnings, with advisory missing bufferView.target hints retained in evidence.

GLB masters are preserved byte-for-byte; gzip files demonstrate derived compression but are not substituted as unvalidated runtime responses. Browser hosting compression is unmeasured. Runtime .ttf files are subsets generated from original upstream variable TTF masters; the originals, source URLs, SHA256 and OFL licence text remain retained. Font derivatives cover the small localized W1 UI and basic Latin/numerals; arbitrary player names may use the user's system fallback. No font weight or language coverage certification was performed. WAV is a genuine generated PCM master with a retained recipe; no audio synthesis service was used. All assets remain placeholders/provisional. No native import was performed.

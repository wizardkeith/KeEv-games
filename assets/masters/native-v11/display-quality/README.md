# C24 central-table quality source (not target accepted)

Original editable `linen-rest.blend` and `stoneware.blend`, generated by the two
`tools/build-v11-display-*.py` authoring programs. JSON exports use metres,
right-handed Y-up; Blender objects use right-handed Z-up. Source and low mesh are
retained separately. No image of the target or a scene is substituted for meshes.

`mug.json` is the two-part existing mug visual variant used ONLY on central table
1 during this quality trial. It is not a new product or grant. `linen-rest.json`
is the actual 880-triangle, 2mm-thick cloth with planar stock-support region and
primary drape. `jug.json` is unintegrated authoring work, NOT playable evidence;
the ordinary flower-holder form is retained with a height-aligned material.

The nine original stoneware / display-linen / display-oak texture inputs live one
directory above, with exact runtime copies under public/assets/native-v11. Their
original field-generation program and SHA records are retained. Albedo describes
reflectance once, roughness is in ORM green, and no window shadow is painted into
the colour texture. Existing floor, other furniture and character/rig sources are
preserved. This in-progress slice has not attained the original reference style.

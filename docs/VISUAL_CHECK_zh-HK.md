# W1.1 小店畫面確認（約 3 分鐘）

本輪雲端瀏覽器可操作介面，但回報「WebGL not supported」，所以沒有聲稱完成真正 3D 構圖、材質、陰影或 FPS 驗收。這份指引供開啟同一 Site 後確認美術候選，毋須安裝開發軟件，亦不是繼續實作的前置條件。

1. 用日常瀏覽器開啟原網址。選「更多」→ 沙盒；沙盒與正常模式各有獨立進度。
2. 收起面板，截一張完整小店：應看到奶油牆、暖木地板、側窗、柔和家具陰影、植物、收銀機與三個陳列架。主標是自己的店名。
3. 入貨少量筆記簿、鉛筆、陶杯與布袋，輪流陳列；截一張可見主要商品輪廓的畫面。筆記簿有書脊、鉛筆有尖端、杯有把手、布袋有提帶。
4. 點架 2，確認柔紫選取底座與面板架號一致。開啟／關閉面板，確認小店沒有被遮住或裁走。可輕拖鏡頭、有限縮放，再試 Zen。
5. 如方便，另截一張窄視窗／手機直向畫面，包括完整底部五項導航及開啟店務面板。這只能代表你所用裝置，不能代替全部手機驗收。

只需留意：太白／太暗、影子太硬、商品太小或難辨認、牆或角色遮住貨架、面板與小店重疊、長字串裁切。如有問題，可附畫面與瀏覽器／裝置名稱；毋須提供存檔或個人資料。

3D 無法啟動時，介面會明確顯示提示，店務、報告、沙盒與存檔仍可使用。此時看到的空白舞台不是美術成果，也不應當成遊戲截圖。

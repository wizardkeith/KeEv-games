# Anime-style direction assessment — current models rejected

The user explicitly rejected the current game models as far from anime style on
2026-10-30. The actual target/reference and v3/new-study comparison support that
judgment. This is an assessment, not another generated candidate or acceptance.

## Geometry/design and lighting must be judged together

- **Reference proportions:** a compact, rounded but deliberately shaped face,
  large head relative to the narrow upper body, short visible neck, soft cheek
  transition and a small understated nose/mouth. Current broad sphere/loft
  constructions read as generic dolls; adjusting only head size or neck length
  has not produced the reference identity.
- **Eyes/expression:** the target uses a designed upper-lid silhouette, warm
  shaded iris, restrained eye white, soft cheeks/brows and a small lively smile.
  Full round eyeballs protruding through approximate sockets, uniform rim lines
  and concentric shiny discs create a toy/goggle appearance. A coherent eye-loop,
  lid and cheek surface design is needed; a technically open socket is not enough.
- **Hair silhouette:** the target's off-centre swept parting, overlapping broad
  and medium locks, smaller exposed forehead, irregular thin returning ends and
  visible own-left clip/ear form one designed mass. A helmet underlayer plus
  repeated closed tubes or floating sheets does not reproduce that organization.
  The rejected NURBS study proved thin surfaces can render, but not fitted roots,
  natural layers or the target silhouette at 200px.
- **Shadow/highlight response:** the target has warm, deliberately organized
  light/shadow and directional hair accents. Smooth uniform PBR highlights and
  a generic studio setup reinforce the current doll-like geometry. The next
  credible approach must design broad shadow shapes, soft transitions, cheek
  colour and hair highlights together with the forms. Simply adding an outline,
  more polygons, grain or a hard two-step ramp is not evidence of matching this
  softer illustrated/anime reference.
- **Material separation:** skin, hair, knit, blouse and linen need different
  visual treatment while maintaining the restrained palette. Roughness changes
  alone did not establish that. The v3 sheen trial also showed that a valid GLB
  can visibly wash out after reimport; native and portable responses need actual
  verification rather than validator-based artistic claims.

## Required proof before applying to the full body

A head-only comparison should demonstrate the reference framing, eye/face
landmarks, swept root/locks and controlled stylized shadow response together,
at the same inferred projection and normal viewing size, before more full-body
variants. The canonical image is not a known camera/3D turnaround: side/back and
hidden details remain inferred. Flat reference-image projection is not an
acceptable substitute for three-dimensional geometry.

Existing Blender can edit meshes, curves and shaders in background, as actually
demonstrated. This does not prove the current author can produce the required
organic sculpt/painting through that route. A deliberately art-directed surface
topology and painting/shading workflow remains missing from the demonstrated
results. Interactive CUA may permit a brush test once app access is approved,
but brush execution would establish only input/save capability, not anime-style
authoring competence. No new plugin/installation is justified by these failures.

No new art variant is produced for this assessment. The failed study is preserved
as evidence; current v3 and game integration remain unchanged and unaccepted.

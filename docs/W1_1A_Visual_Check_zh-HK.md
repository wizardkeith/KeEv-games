# W1.1A 畫面回傳指引

本輪雲端瀏覽器重新測試後仍回報 `WebGL not supported`。已完成及更新可玩的美術候選；3D 光影與動效觀感未被實際看到。唔需要安裝工具或更改任何安全設定。

用平時可玩到 3D 嘅同一網址，保留你現有進度；唔使重開或匯入任何存檔。方便時只需以下三種畫面：

1. 「更多 → 欣賞小店」的 Zen 全景，見到地板、窗邊、櫃台同三個陳列架。
2. 選中陳列架 2，打開入貨或店務面板的正常畫面；可用你平時的手機闊度。
3. 拉近筆記簿、鉛筆、陶杯、布袋及通用店員，盡量同時見到受光面同陰影面。現有存貨有幾款就拍幾款，唔需要額外購買。

如果方便，可把其中一次回傳改成 10–15 秒短片：選架、完成平時需要的入貨／陳列，或觀察店員與窗邊；無需特登重播已開過的樣品。若剛好首次開樣品，略過後完成卡應仍然保留。

畫面旁寫上裝置／瀏覽器、畫質（自動／標準／簡約）、最少特效有冇開、系統有冇減少動態即可。待核對：曲面受光是否自然、陶杯口與布袋輪廓、顧客有冇穿模、選架與收據回饋是否夠清楚又唔搶眼、窄屏世界可操作空間、動效是否低調順暢。以上係後續調整依據，唔係本輪開始或交付的前置條件。
